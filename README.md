# Stage 模擬器

IPSC Action Air stage 的規劃、回放與檢討工具。網頁程式，可安裝成手機 App（PWA），離線使用。

操作說明見〈使用手冊.md〉；策略原則見〈策略資料庫.md〉；架站與手機安裝見〈架站與安裝教學.md〉；功能規格與設計決定見 spec.md。

## 資料

你的 stage、路線計畫、射手資料、實測紀錄與影片標記都只存在你自己裝置的瀏覽器裡，不會上傳到這個儲存庫。
